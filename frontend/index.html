🖥️ QGIS Integration

Load live hazards directly into QGIS Desktop:
📥 Download GeoJSON Snapshot
Open QGIS → Layer → Add Layer → Add Vector Layer
Source type: Protocol: HTTP(S)
URI: paste the GeoJSON URL above (ends in .geojson)
Click Add — hazards appear as points on your QGIS canvas
Right-click layer → Properties → Style → categorize by severity field
For live auto-refresh: install the ReloadLayer QGIS plugin and set interval to 30s
Optional filters: append ?severity=critical or ?since=1700000000 to the URL
WFS-style params:
?severity=critical — filter by level
?bbox=120.97,14.59,121.00,14.61 — spatial filter
?since=<unix_ts> — time filter
